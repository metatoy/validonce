validonce schemas

Canonical, versioned schemas for validonce, which carries cross-field validation rules in OpenAPI and JSON Schema under x-validonce. A published version never changes; a new version gets a new file.

  • rules-v1.json: the rule format v1 (the value of x-validonce)
  • rules-file-v1.json: a standalone rules file (validonce extract --format json), conventionally *.validonce.json
  • dialect-v1.json: JSON Schema 2020-12 plus the validonce vocabulary
  • vocab/rules-v1: the vocabulary
  • conformance-case-v1.json: the shared conformance case files, for other implementations
  • regex-case-v1.json: the regex portability fixtures

Source of truth: conformance/schema/ and schemas/ in the repository; this site is built from it on every change to main.
