validonce rules vocabulary, version 1

https://schemas.metatoy.com/validonce/vocab/rules-v1 is the URI of a JSON Schema 2020-12 vocabulary with one keyword:

  • x-validonce: an object of cross-field validation rules (required_when, compare, at_least_one_of, exactly_one_of, all_or_none) for the instance the schema describes. Its value must validate against rules-v1.json. Its meaning is defined by the validonce rule format v1, with shared conformance cases in the same repository.

The validonce dialect (dialect-v1.json) declares this vocabulary as optional on top of the standard 2020-12 vocabularies. A validator that does not implement it still processes the schema and treats x-validonce as an annotation. In OpenAPI 3.1, set jsonSchemaDialect to the dialect URI to opt in.

Implementations: C# (FluentValidation, ASP.NET Core), Python (Pydantic, FastAPI) and TypeScript (Zod, React, Angular), from github.com/metatoy/validonce (Apache-2.0).
