# Onboard your agent to validonce

Give your coding agent the validonce MCP server and the migration skill, then hand it one prompt. It finds the
cross-field checks in your project, drafts the rules, and proves nothing changed before it migrates anything.

## 1. Connect your agent

The server runs locally with `npx -y validonce-mcp` (Node 20 or later). It needs no API key and makes no network
calls.

<TabItem value="claude" label="Claude Code" default>

```text
/plugin marketplace add metatoy/validonce
```

</TabItem>
<TabItem value="vscode" label="VS Code (Copilot)">

One click: <a href="vscode:mcp/install?%7B%22name%22%3A%22validonce%22%2C%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22validonce-mcp%22%5D%7D">Install in VS Code</a>

```json
{

    "validonce": { "type": "stdio", "command": "npx", "args": ["-y", "validonce-mcp"] }
  }
}
```

Then pick **Agent** mode in Copilot Chat and enable the `validonce` tools.

</TabItem>

## What happens next

The agent reads the [docs index](pathname:///llms.txt), lists your cross-field checks, classifies each one, and
proposes rules. With the MCP server connected it checks them, runs your old validator against the new rules on
generated inputs (only after you agree), and migrates only the rules that match. Nothing is committed for you.
See [Migrating with an agent](/docs/agentic-migration) for the full workflow, its safety rules and what has been
tested.
