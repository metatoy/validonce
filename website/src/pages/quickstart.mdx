# Choose your stack

validonce has two halves. On the **server** you write cross-field rules in your own language, and validonce
exports them into your OpenAPI document under `x-validonce`. In the **browser** a small runtime reads those rules
and checks the form before it is sent. The server still checks every request.

## 1. Pick your server

Each tab shows the same four rules for the playground's Contact form: email or phone, a full address or none of
it, a postal code when the country is US, and an end date on or after the start date. Pick a tab once and every
code sample on this site follows it.
