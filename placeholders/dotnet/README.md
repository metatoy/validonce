# validonce

This package name is reserved for **validonce**, an open-source library in development by Metatoy LLC.

validonce lets you write cross-field validation rules once on the server (ASP.NET Core with FluentValidation, or FastAPI with Pydantic) and enforce the same rules in React and Angular forms.
